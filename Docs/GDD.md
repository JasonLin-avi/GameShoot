## 一、游戏概述

### 1.1 核心体验陈述
在这个游戏里，玩家感受到：**「精準操控砲火穿過數學倍率門，瞬間觸發幾何級數的萬人藍色大軍，如海嘯般正面粉碎壓境紅軍的極致爽快感與逆風翻盤的策略成就感。」**

### 1.3 游戏简介
《軍團防線：增殖衝擊》是一款受經典副玩法廣告素材與《Mob Control》、《Count Masters》啟發的輕度 3D 休閒塔防射擊遊戲。玩家位於螢幕下方，藉由單指左右拖曳控制射擊發射點，發射藍色小兵/子彈穿過在戰場中平移或固定的「數學倍率門（+10, x2, x3, ÷2 等）」，將微小的兵力迅速複製為龐大的藍色軍團。
畫面頂端則有源源不絕的紅色敵軍大軍壓境（包含普通紅軍步兵、具有遠程/飛行特性的石像鬼、以及血厚防高的大型 Boss）。藍軍與紅軍在中央戰場展開即時物理對撞消滅。玩家必須具備動態算術判斷力與微操走位，死守底線不被突破，並徹底肅清來犯敵軍。

### 1.4 目标玩家画像
| 維度 | 結論 | 對設計的影響 |
|------|------|--------------|
| 受眾取向 | 泛用戶／輕度手遊玩家（偏好短平快、視覺衝擊強烈） | 規則必須在 5 秒內理解，不需要複雜文字教學，靠動態視覺引導 |
| 年齡層 | 12-45 歲全客群 | 算術規則限定在簡易加減乘除，節奏緊張但不刁難計算速度 |
| 核心動機 | 放鬆解壓、數字膨脹爽感、即時回饋、挑戰高波次 | 強化人數增殖時的音效、相機微震動與同屏碰撞的打擊反饋 |
| 遊玩頻率 | 零碎短時段（通勤、摸魚、等待），日均 3-5 次會話 | 單局控制在 60-90 秒內完成，隨開即玩、無繁雜載入 |
| 內容邊界 | 綠色全年齡友好，規避寫實血腥、恐怖驚嚇與複雜付費套路 | 角色採用極簡幾何膠囊人（Capsule / Low-poly），死亡化為彩色泡泡或幾何碎屑 |

## 二、核心玩法

### 2.1 核心循环
玩家的單局操作與成長鏈由以下 4 步構成閉環：

```
[1. 觀察戰局] ──> [2. 滑動瞄準倍率門] ──> [3. 人數爆發與對撞消滅] ──> [4. 結算獎勵與局外成長]
      ↑                                                                         │
      └────────────────────────── [強化三維屬性/解鎖新關卡] ──────────────────────┘
```

1. **觀察戰局**：辨識上方紅軍的刷新波次、行進路線與倍率門的移動軌跡（例如一個 +20 門在左，一個 x3 門在右）。
2. **滑動瞄準**：單指在螢幕下方水平滑動，引導藍軍發射流持續射入最佳收益的數學門。
3. **對撞消滅**：穿過倍率門的藍軍規模劇增，與迎面衝下的紅軍兵線發生抵消式對撞，防守底線並消滅菁英/Boss。
4. **結算與成長**：通關或生存結算獲得金幣，回主畫面升級「射速、初始兵力、金幣加成」，解鎖後續難度或刷新作死無盡紀錄。

### 2.2 玩法深度
- **即時心算決策**：倍率門非靜態，包含固定門、橫向巡弋門、旋轉隱藏門。當左側為「+15」、右側為「x2」時，若當前發射量少於 15 則走加法，部隊累積後轉切乘法。
- **動態弱點集火**：
  - **普通小兵**：以大群體對撞即可相互 1:1 抵消。
  - **巨型 Boss**：體型龐大、移動緩慢但需消耗數十乃至上百名藍軍才能推倒，需要集中火力持續射擊。
  - **石像鬼 (Gargoyle)**：低空飛行單位，能無視前方部分藍軍步兵的推擠直接威脅底線，需要玩家迅速將砲火轉移至其正下方直接攔截。
- **雙模式架構**：
  - **關卡模式**：預設波次（通常 3-5 波），在限時或固定敵兵數下全殲敵軍即算三星通關。
  - **無盡生存 (Endless Waves)**：敵人速度與血量隨時間線性增長，數學門出現負數干擾（如 -5, ÷2），比拼生存秒數與總擊殺數。

### 2.3 主要系统
- **發射與倍增系統**：控制子彈生成速率與通過數學門的邏輯轉化。
- **物理衝撞與實體管理系統**：維護藍紅兩軍的空間聚集、碰撞檢測與 1:1 或比例消亡邏輯。
- **敵人波次生成器 (Wave Spawner)**：根據關卡進度與難度曲線動態產出敵軍與數學門。
- **局外數值升級系統**：金幣消耗、等級遞增與離線收益。
- **無盡排行榜系統**：基於本地儲存 (LocalStorage) 及預留雲端 API 的分數排行展示。

### 2.4 操作方式
- **操控設備**：手機觸控螢幕（單指滑動）或 PC 滑鼠（左鍵按住拖曳）。
- **操控範圍**：螢幕下緣 1/4 區域水平拖曳。
- **操作反饋**：發射點帶有動態虛線軌跡或箭頭導引；藍軍穿過門時產生微縮放動畫、數值飄字與音效回饋。

## 三、系统详细设计

### 3.1 射擊與數學倍增系統
- **發射基座**：固定在螢幕底部中央水平軸線 $(Y = 0, Z = \text{底線})$，依玩家滑動在 $X \in [-X_{\max}, X_{\max}]$ 間平滑移動。
- **多聯裝並排連續發射機制 (Multi-Barrel Parallel Stream)**：
  - 核心規格改進：拋棄「開局一次性全出、後續單發單列」的割裂體驗，改為**砲台每次開火均同時並排射出 $N$ 顆子彈 ($N = 2, 3 \text{ 或 } 4$)**。
  - **平行方陣排布**：子彈以砲台中心為基準，橫向等距對稱排列（間距 $\Delta X = 0.4$）：
    - **雙聯排 ($N=2$)**：$X_{\text{offset}} \in \{-0.2, +0.2\}$，形成緊湊的雙兵衝鋒列。
    - **三聯排 ($N=3$)**：$X_{\text{offset}} \in \{-0.4, 0, +0.4\}$，標準三箭頭三角/平列推進。
    - **四聯排 ($N=4$)**：$X_{\text{offset}} \in \{-0.6, -0.2, +0.2, +0.6\}$，形成覆蓋半條跑道寬度的重裝步兵排面。
  - **連續兵浪推進**：隨著射擊間隔連續觸發，畫面上呈現從「雙排波次」到「三排/四排波次」源源不絕、層層推擠向前的震撼浪潮感。
  - **穿門增殖效應**：並排子彈同時穿透倍率門時，倍增產生的小兵在橫向與縱向立體展開，形成極具張力的幾何級數藍軍海嘯。
- **數學倍率門 (Math Gate)**：
  - **外觀**：具有藍色/綠色半透明發光質感的拱門，中央懸浮動態三維字體（如 `+10`、`×2`、`×3`，偶爾出現紅色懲罰門如 `-5`、`÷2`）。
  - **觸發邏輯**：當單一藍軍小兵通過門邊界時：
    - 加法門 (`+N`)：在該小兵兩側額外分裂複製出 $N$ 個單位。
    - 乘法門 (`×M`)：該小兵分裂為 $M$ 個單位。
    - 懲罰門 (`-N` / `÷M`)：消耗進入的小兵或按比例湮滅。
  - **動態門機制**：部分關卡中的門會以正弦曲線左右移動，考驗玩家跟隨滑動射擊的微操技巧。

### 3.2 陣營兵種與敵方 AI 行為系統
| 兵種名稱 | 陣營 | 速度 | 生命值 (HP) | 特殊行為 / 應對策略 |
|---------|------|------|-------------|---------------------|
| **藍軍常規兵** | 玩家 | 快 (基準 1.0) | 1 | 穿門倍增，向前直線衝鋒，接觸紅軍時以 1:1 抵消對手 |
| **紅軍常規兵** | 敵方 | 中 (基準 0.6) | 1 | 成群結隊直線向下推進，企圖衝垮防線 |
| **巨型頭目 (Red Boss)** | 敵方 | 慢 (基準 0.25) | 30 ~ 100 | 體型為常規兵 3 倍，具有強力擊退抗性，需要上百藍軍連續衝撞擊殺 |
| **石像鬼 (Gargoyle)** | 敵方 | 快 (基準 0.9) | 3 ~ 5 | 低空拍翅飛行，在地面無藍軍攔截時可越過前方交火線直切玩家底線 |

- **底線防禦機制**：玩家後方設有一條防守能量盾（預設 3 點耐久值）。一般小兵漏怪扣 1 點，Boss 突破直接扣 3 點導致遊戲結束 (Game Over)。

### 3.3 關卡推進與無盡防守系統
1. **關卡模式 (Stage Mode)**：
   - 包含 10 個由淺入深的關卡。
   - 關卡 1-3：固定加法與乘法門，教導玩家理解增殖效應。
   - 關卡 4-6：出現左右巡弋的動態門，加入混合兵種（紅軍 + 石像鬼）。
   - 關卡 7-10：加入負數懲罰門、障礙物石柱，最終波次出現巨型頭目。
2. **無盡生存模式 (Endless Mode)**：
   - 無固定終點，隨著生存波次增加：
     - 敵方生成頻率每 30 秒提升 15%。
     - 出現負向門概率提高（考驗避開陷阱的能力）。
     - 每撐過 60 秒刷新一隻狂暴 Boss，獎勵大量金幣。

### 3.4 局外金幣成長與三維升級系統
玩家在關卡內擊殺紅軍可獲得金幣，在大廳介面可進行 3 項核心屬性升級：
1. **發射射速 (Fire Rate)**：增加單位時間內的射擊次數（每秒發射數從 2 發提升至 10 發）。
2. **聯裝排數 (Barrel Stream Columns)**：升級砲台發射管數，使每次連續開火同時並排射出的子彈數從雙排 (2 顆) 擴展至三排 (3 顆)、四排 (4 顆)，並附帶開局微量護衛前鋒。
3. **金幣倍率 (Coin Multiplier)**：提升關卡擊殺敵軍及過關獲得的金幣加成百分比。

## 四、数值设计框架

### 4.1 核心数值体系
- **基礎射速公式**：
  $$\text{FireInterval} = \max(0.08\text{s}, 0.5\text{s} - 0.035 \times (\text{Lv}_{\text{Rate}} - 1))$$
- **並排發射顆數與座標分佈公式**：
  $$N_{\text{stream}} = \min(4, 2 + \lfloor (\text{Lv}_{\text{Stream}} - 1) / 3 \rfloor)$$
  - $\text{Lv}_{\text{Stream}} \in [1, 3]$：雙排發射 ($N = 2$)
  - $\text{Lv}_{\text{Stream}} \in [4, 6]$：三排發射 ($N = 3$)
  - $\text{Lv}_{\text{Stream}} \ge 7$：四排發射 ($N = 4$)
  - 子彈橫向座標分佈：
    $$X_i = X_{\text{cannon}} + \left(i - \frac{N_{\text{stream}} - 1}{2}\right) \times \Delta X, \quad i \in [0, N_{\text{stream}} - 1], \; \Delta X = 0.4$$
- **三維升級成本公式**（經典等比遞增曲線）：
  $$\text{Cost}(\text{level}) = \text{BaseCost} \times (1.25)^{(\text{level} - 1)}$$
  - 基礎射速 BaseCost = 100
  - 聯裝排數 BaseCost = 150
  - 金幣倍率 BaseCost = 200
- **敵軍推進速度與波次縮放**：
  $$\text{EnemySpeed} = \text{BaseSpeed} \times (1 + 0.05 \times \text{WaveIndex})$$

### 4.2 成长曲线
- **前期 (1-3 關 / 生存 0-60 秒)**：金幣掉落充沛，前 5 級升級在 3 場遊戲內即可達成，給予強烈的實力增長反饋。
- **中期 (4-7 關 / 生存 61-180 秒)**：單純提升發射率不足以硬過，玩家必須精準捕捉每一扇「x2 / x3」動態門，突出策略操作的重要性。
- **後期 (8-10 關 / 生存 180 秒+)**：需要將三維屬性均勻提升至 Lv.10 以上，並在 Boss 出現時預先囤積大量藍軍形成「部隊浪潮」才能成功通關。

### 4.3 核心指标定义
| 指标 | 目标值/观察方式 | 设计含义 |
|------|------------------|----------|
| **原型完成度** | 核心增殖與對撞功能 100% 跑通，支援手機觸控 | 驗證核心循環玩法是否具備原生吸引力 |
| **首日遊玩時長** | 試玩平均大於 6 分鐘（完成 4-5 局以上） | 驗證首期吸引力與重玩誘因 |
| **單局平均會話時長** | 關卡模式 75 秒，無盡模式 120 秒 | 確保節奏符合輕度超休閒的碎片化定位 |
| **第 3 關留存通過率** | 新玩家前 3 關通關率 > 75% | 確保新手教學坡度平緩，無惡意卡關點 |
| **效能幀率 (FPS)** | 手機 Safari / Chrome 與 PC 穩定 55-60 FPS | 確保同屏 500+ 實體時無卡頓掉幀 |

## 五、美术需求清单

### 5.1 角色美术
- **玩家發射砲台**：機械感 Low-poly 底座，配備對應等級的可視化多聯裝發射管（雙管、三管、四管金屬圓柱筒），發射時伴隨砲口微後坐力縮放動畫與能量光暈。
- **藍軍戰士**：極簡圓頭膠囊體，高亮皇家藍 (#1E88E5)，頭頂微小鋼盔裝飾，多列並排時呈現緊湊的步兵方陣儀仗感。
- **紅軍步兵**：對比緋紅色膠囊體 (#E53935)，帶有生氣的簡易眼部貼圖或稜角。
- **巨型頭目 (Boss)**：紅軍常規兵放大 3 倍，肩部有金屬刺甲 Low-poly 幾何體。
- **石像鬼 (Gargoyle)**：深灰偏紫褐色幾何飛翼模型，拍動扇形雙翼，陰影投影在地面上。

### 5.2 场景美术
- **戰鬥跑道 (Arena)**：帶有微弱網格紋理的淺灰白地面，兩側有半透明霓虹邊界防護欄。
- **數學倍率門**：高科技半透明能量門框，頂部漂浮發光加減乘除標誌，藍綠色代表增益，紅色代表減益。
- **底線安全區**：藍色呼吸燈能量帶，受到攻擊時閃爍紅光。

### 5.3 UI 设计
- **戰鬥 HUD**：
  - 頂端：關卡推進進度條 / 無盡模式計時器與波次計數。
  - 右上角：當前累積金幣與即時幀率 (Debug 開關)。
  - 下方：直覺的「左右滑動發射」新手手勢指引動畫（首次進入時展示 3 秒後自動隱藏）。
- **結算與升級介面**：
  - 勝利/失敗彈窗：醒目的大字體與獲得金幣動畫。
  - 大廳三維升級按鈕：清楚標註當前等級、效果數值與升級所需金幣。

### 5.4 特效音效
- **視覺特效 (VFX)**：
  - 穿門特效：微小粒子爆發與數字放大浮動跳動。
  - 碰撞消滅：小兵碰撞時散發藍紅光芒，並有微型幾何碎片炸裂。
  - Boss 倒地：全螢幕微震動 0.2 秒與環形衝擊波。
- **音訊需求 (SFX)**：
  - 輕快有節奏感的打擊發射音 (Pop sound)。
  - 人數倍增時音調遞增的叮叮聲 (Chime scale)。
  - 敵兵消滅的爆裂聲與 Boss 警告警報。

## 六、技术架构建议

### 6.1 推荐引擎
- **核心庫**：Three.js (r160+) + 原生 WebGL。
- **選擇理由**：
  1. 完全無需玩家下載任何客戶端，透過 URL 或 QR Code 即開即玩，極大降低試玩與分享門檻。
  2. 現有專案環境已建立 `Test.html` 之 Three.js 基礎，可直接沿用並快速迭代。
  3. 對於個人獨立開發者，Web 技術除錯便利，支援熱重載，且能透過 PWA 或 Capacitor 一鍵打包為原生 App。

### 6.2 核心技术点
1. **大群體實體渲染最佳化 (`THREE.InstancedMesh`)**：
   - 絕不能為每隻小兵建立獨立的 `Mesh`。
   - 使用單一 `InstancedMesh` 管理 1000 隻藍軍與 1000 隻紅軍，透過動態更新 `instanceMatrix` 達到 1 次 Draw Call 渲染千人同屏，確保 60FPS。
2. **空間網格分割碰撞檢測 (Spatial Grid Partitioning)**：
   - 不使用開銷巨大的通用 3D 物理引擎（如 Cannon.js/Ammo.js），改用極輕量自研 2.5D 網格檢測。
   - 將戰場劃分為 $10 \times 30$ 的網格單元，僅對同一網格單元內的藍軍與紅軍計算歐氏距離平方，大幅降低 $O(N^2)$ 碰撞計算消耗至 $O(N)$。
3. **RWD 響應式相機適配 (Aspect Ratio Adaptor)**：
   - 動態監聽 `window.resize`，依據螢幕比例自動調整相機視野 (FOV) 或正交縮放，確保在各品牌手機直式螢幕與 PC 瀏覽器均能完整看清兩側邊界與前進縱深。

- **展示內容**：第 3 關（長度 90 秒）及無盡生存模式前 3 波。

## 八、开发里程碑

### Phase 1: 核心玩法验证 (第 1 週)
- **目標**：跑通最純粹的最小可玩原型 (Playable Prototype)。
- **交付物**：單一 HTML 頁面，包含：底座滑動發射、1 個固定倍率門、基本紅軍下壓與碰撞消滅邏輯。
- **驗證指標**：無報錯運行，小兵順暢分裂，勝負邏輯生效。

### Phase 2: 系统完善 (第 2 週)
- **目標**：加入特殊敵軍（石像鬼、巨型 Boss）與動態移動門。
- **交付物**：自研空間分割碰撞演算法上線，支援 InstancedMesh，加入石像鬼飛行繞後與 Boss 耐久對撞。
- **驗證指標**：同屏實體達 500+ 時維持 60FPS。

### Phase 3: 内容填充 (第 3 週)
- **目標**：完成關卡配置、無盡生存模式與局外金幣三維升級。
- **交付物**：10 個測試關卡、Endless Mode 計時排行榜、大廳升級介面與本地資料存檔。
- **驗證指標**：能完整跑完「戰鬥 -> 結算 -> 升級數值 -> 提升再戰」之完整循環。

### Phase 4: 打磨上线 (第 4 週)
- **目標**：音效集成、粒子特效拋光、手機端觸控與橫直螢幕 RWD 自適應。
- **交付物**：完整可發布之 Web 遊戲成品，支援離線快取 (PWA) 或一鍵佈署至 GitHub Pages / Vercel。
- **驗證指標**：各主流手機瀏覽器點開即玩，平均會話時長達標。

## 九、风险评估

### 9.1 技术风险
- **風險描述**：大量實體在瀏覽器端碰撞檢測導致 CPU 負載過高，手機瀏覽器掉幀發燙。
- **緩解策略**：
  1. 嚴格限制小兵碰撞採用 2D 俯視距離簡化計算，不進行複雜 Mesh/凸包檢測。
  2. 設定同屏上限閥值（如單方上限 300 隻），超過時自動合併為「精英大型藍兵（1 抵 5）」。

### 9.2 市场风险
- **風險描述**：該題材市面上已有若干成功作品（如 Mob Control），副玩法熱度可能衰退。
- **緩解策略**：強調「直式免下載即開即玩」的 Web 微端優勢，主打快速解壓、極速載入與加入「石像鬼/無盡防守」的特殊微創新。

### 9.3 生产风险
- **風險描述**：身為個人獨立開發者，容易陷入「過早追求精緻美術貼圖與複雜裝備系統」而延誤上線。
- **緩解策略**：堅守 Low-poly 極簡幾何視覺與 MVP 切片原則，第一階段堅決不導入複雜裝備庫與劇情文本，以驗證核心手感為第一優先。
