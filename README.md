> **「在 6 通道戰場中極限分配火力——左路穩健回血、中路精準打斷敵軍蓄力、右路分期擊碎石柱迎來 ×N 倍率瞬間灌滿 150 顆同屏子彈上限，以密集 4 聯排彈幕洪流正面粉碎壓境紅軍的極致策略爽快感！」**

《軍團防線：增殖衝擊》是一款基於 **Three.js** 與原生 WebGL 開發的 3D 超休閒策略射擊／彈幕配額生存塔防遊戲（Casual Tactical Shooter & Bullet-Quota Defense）。本作獨創 **「同屏子彈配額即血條（150 顆上限 / 單排 4 顆寬度）」** 與 **「左 1 加、中 4 防、右 1 破柱乘算」** 的 6 單位分道博弈機制，搭配敵軍底線週期性蓄力讀條拆彈與鋼鐵人英雄雙主動技能，零外部肥大依賴、免安裝點開即玩，支援手機直式螢幕觸控（含邊緣通道磁吸輔助）與桌面端鍵鼠微操。

## ✨ 核心特色與機制創新 (v3.1)

### 1. 🛣️ 6 單位橫向分道博弈：「左 1 加、中 4 防、右 1 破柱乘算」
戰場總寬度（$W = 12$）精確切分為 **6 個邏輯通道單位（Lanes 1 ~ 6）**：
- **左路（Lane 1，寬 1 單位）—— 穩健回血與墊高基底**：持續向底線推進 `+2, +4, +8...` 強化門，無石柱阻擋。殘血時可隨時滑至左路無門檻急救，或先墊高基礎配額再轉右路乘算。
- **中路（Lanes 2~5，寬 4 單位）—— 紅軍四階兵種直線壓境**：所有敵軍嚴格沿垂直直線推進（$V_x = 0$），具備獨立血條與階層定位：
  - **Lv.1 紅軍斥候 (`6 HP`)**：移速快、成群刷新，底線每 `1.0s` 攻擊扣除 `-2` 配額。
  - **Lv.2 突襲石像鬼 (`16 HP`)**：極速俯衝逼近底線，底線每 `1.5s` 攻擊扣除 `-5` 配額。
  - **Lv.3 重裝巨盾兵 (`48 HP`)**：前排高威脅肉盾，底線蓄力 `2.5s` 重擊扣除 `-15` 配額。
  - **Lv.4 毀滅巨像 Boss (`240~400 HP`)**：終極壓迫頭目，底線蓄力長達 `4.0s`，單次重擊扣除 `-35` 配額。
- **右路（Lane 6，寬 1 單位）—— 停駐裝甲石柱 + `×N` 狂暴倍增門**：
  - 按 `[停駐石柱] -> [×N 倍率門]` 交錯排隊，首根石柱推進至前線定點（$Z_{\text{stop}}$）即**停駐不動**並阻塞後方 `×5 / ×10 / ×15` 強化門。
  - **分期付款破柱與震波保護**：石柱受擊傷害永久累積不回血；擊碎石柱瞬間釋放**橫向金色破柱震波**（擊退中路敵軍並強制重置所有底線敵軍的蓄力讀條），同時解鎖後方 `×N` 門直衝底線，一舉將子彈配額拉滿至 **150 顆上限**！

### 2. 💎 同屏子彈配額即血條 (Bullet-Quota Health System)
- **生存與火力合一**：取消傳統獨立血條，玩家當前的「子彈配額 $Q \in [0, 150]$」即是生命值，也是畫面上可同時維持飛行的最大子彈總數；當 $Q \le 0$ 時即告落敗（Game Over）。
- **單排 4 顆寬度 × 同屏 150 顆上限**：砲台每次開火固定並排射出 **4 顆子彈**（收納於 1 個通道寬度內，$V_x = 0$ 筆直飛行）。滿配額 `150 / 150` 時，畫面呈現 **37 排 × 4 顆** 金色流光彈幕瀑布，5 秒內即可正面融化巨型 Boss！
- **瀕死狂暴保護 (Last Stand Buff)**：當配額跌至 $Q \le 8$（不足 2 排）時，系統自動觸發 **射速與子彈飛行速度 +35%** 狂暴加成，助玩家在絕境中拆彈或破柱翻盤。

### 3. ⏱️ 敵軍底線週期性讀條與「極限拆彈」微操
- 敵軍抵達防線底線後不會立即自爆，而是停駐並啟動各自的**蓄力紅圈倒數計時器（`1.0s ~ 4.0s`）**。
- 當敵軍讀條超過 `70%` 時觸發底線紅光警報；若玩家在紅圈填滿前轉火將該敵軍 HP 打空，即可完成**零傷極限拆彈（Last-Second Defuse）**！

### 4. 🤖 鋼鐵人英雄雙主動技能 (Iron Man Active Skills)
- **`[E]` 胸口集束巨砲 (Unibeam)**：釋放高能貫穿光束，瞬間蒸發直線上所有紅軍與護盾。
- **`[Q]` 肩部微型追蹤導彈 (Micro-Missiles)**：齊射多枚具備高拋物線與尾煙軌跡的智慧導彈，精準轟炸中路高威脅目標。

### 5. 📊 v3.1 戰術指標追蹤與指揮官段位評級
- 單局即時統計 **破柱數 (Pillars Broken)**、**滿編 `MAX 150!` 觸發次數**、**底線極限拆彈次數 (Defuses)** 與 **左/中/右三區轉火切換次數**。
- 結算與無盡排行榜自動授予指揮官段位徽章（**青銅新兵 ➔ 白銀衛士 ➔ 黃金統領 ➔ 鑽石戰神 ➔ 王者防線指揮官**）。

### 6. 🚀 恆定 150 子彈池與 60 FPS 極致效能
- 由於同屏子彈嚴格封頂為 `150` 顆，預分配容量 180 的 `THREE.InstancedMesh` 搭配 6 通道空間分桶碰撞檢測（Lane Bucket Culling），徹底根除後期數值膨脹導致的手機發燙與掉幀問題，任何裝置皆穩定 60 FPS。

## 🏆 遊戲模式與成長曲線

1. **關卡模式 (Stages 1 ~ 10)**：
   - 依循 **v3.1 三階段心流曲線**：`0~30s 暖身建立期`（15 秒內破首根 `32 HP` 石柱體驗首次 `MAX 150!`）➔ `30~60s 雙線拉鋸期`（石像鬼與重裝巨盾兵穿插，分期偷打石柱）➔ `60~90s 高潮決戰期`（對決毀滅巨像 Boss，利用左路 `+8/+12` 急救與右路 `×10/×15` 絕地反殺）。
2. **無盡生存模式 (Endless Survival)**：
   - 隨波次動態縮放敵軍血量係數 $M_{\text{HP}}(S)$、右路石柱血量 $\text{HP}_{\text{pillar}}(S, k)$ 與左右路 `+N / ×N` 補給倍率，挑戰極限生存時間、總擊殺數與最高指揮官段位（支援 LocalStorage 本地排行榜）。

## 🚀 快速開始 (Quick Start)

本專案為純前端靜態架構，無須建置步驟（No Build Steps Required）：

### 方式 1：使用本機靜態伺服器 (推薦)
```bash
# 使用 Python 快速啟動
python -m http.server 8080

# 或使用 Node.js http-server / serve
npx serve .
```
啟動後在瀏覽器開啟 `http://localhost:8080` 即可暢玩！

### 方式 2：使用 VS Code 擴充套件
- 在 VS Code 中安裝 **Live Server**。
- 對著 `index.html` 按右鍵，選擇 **"Open with Live Server"**。
